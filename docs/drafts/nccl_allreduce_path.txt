ncclDevFuncId(int coll, int devRedOp, int type, int algo, int proto):
  - Computes row index into kernel table based on:
    - coll: ncclFuncAllReduce (4)
    - devRedOp: Reduction operation (Sum, Prod, etc.)
    - type: Data type (f32, f64, etc.)
    - algo: NCCL_ALGO_RING (1)
    - proto: NCCL_PROTO_SIMPLE (2)
  - Returns ncclDevFuncRowToId[row] = kernel function ID
  
For AllReduce RING SIMPLE with Sum and float32:
  row = 1 + (nAlgos_AG*protos)*4 + ((redOp*types + type)*6 + 1)*3 + 2
      where nAlgos_AG=4, protos=3, redOp=0, types=12, type depends on dtype

12. COMMUNICATION EXECUTION
============================

The Primitives class (with ProtoSimple specialization) implements methods:
  - directSend(offset, offset, nelem)
  - directRecvReduceDirectSend(offset, offset, nelem)
  - directRecvCopyDirectSend(offset, offset, nelem)
  - directRecv(offset, nelem)

Each method uses ProtoSimple's parameters to:
  - Determine step size: Proto::calcBytePerStep()
  - Synchronize between peers using barriers
  - Perform data transfers in the SIMPLE protocol style
  - Execute reduction operations inline

File: /workspace/nccl/src/device/prims_simple.h
Lines: 200-400+ (various communication methods)

The SIMPLE protocol:
  - Uses direct memory access (full payload per step)
  - Simpler than LL (Low Latency) which uses flag-based signaling
  - Better for large messages where latency is less critical
  - Uses thread synchronization barriers

SIMPLE PROTOCOL CHARACTERISTICS
===============================

The Simple Protocol is selected by topoGetAlgoInfo() based on cost tables.
It is characterized by:

1. Direct memory access patterns (no flag-based flow control)
2. Full data payload per step (not split like LL)
3. Barrier-based synchronization between thread groups
4. Suitable for large messages (bandwidth-optimized)
5. Less latency-sensitive than LL protocol

Configuration in ProtoSimple template:
  - SlicePerChunk, StepPerSlice: Chunking parameters
  - Unroll: Loop unrolling factor
  - MultimemSrcs/Dsts: Multimem source/destination count
  - calcBytePerStep(): Returns total buffer size / NCCL_STEPS
